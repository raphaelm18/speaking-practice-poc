# Speaking & Listening Practice — POC

Purpose:
Explore a lightweight speaking practice experience for ELL students
that helps teachers quickly see useful signals without formal assessment.

This is a concept prototype.
It prioritizes believability, clarity, and teacher usefulness over accuracy or scale.

Non-goals:
- High-stakes assessment
- Precise scoring
- Standards validation
- Production readiness

Rubric focus for this POC:
- Idea completeness
- Topic coherence
- Elaboration
- Vocabulary use

Levels are qualitative only (Beginning / Developing / Strong).
No numeric scores.

Each dimension is described using qualitative levels only.

Levels:
- Beginning: Ideas are present but incomplete or loosely connected.
- Developing: Ideas are mostly clear and connected, with some expansion.
- Strong: Ideas are clear, complete, and appropriately developed.

These are observational labels, not scores.
When evidence is limited, prefer the lower or middle level.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Set your OpenAI API key:
   ```bash
   export OPENAI_API_KEY=your_api_key_here
   ```
   Or create a `.env` file (see `.env.example`).

3. Run the analysis:
   ```bash
   python app.py
   ```
